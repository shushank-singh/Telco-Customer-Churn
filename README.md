# 🧠 Project Overview

This project uses Machine Learning to analyze telecom customer behavior and predict customer churn probability.

The system includes:

* 🤖 Machine Learning model
* 🚀 FastAPI backend
* 🎨 Streamlit frontend
* 🌍 Cloud deployment
* ✅ Data validation using Pydantic
* 📊 Churn probability + risk analysis
